# Humanoid Everywhere — Project Page

Project website for **"Humanoid Everywhere: Large-Scale Real-to-Sim Environment and Data Generator for Humanoid Loco-Manipulation"** (RSS 2026 Workshop on Data-Centric Robotics).

Junying Wang, Xinjie Chen, Yunkai Zhan, Junsoo Kim, Songlin Wei, Xulang Guan, Vitor Guizilini, Chuhang Zou, Jiageng Mao, Yue Wang
— University of Southern California, Toyota Research Institute, Meta Reality Lab Research

## Structure

- `index.html` — the project page (goal, motivation, pipeline, results, demos)
- `img/` — figures exported from the paper (`.pdf` sources kept alongside web `.jpg`/`.png`)
- `video/` — demo videos:
  - `our_goal.mp4` — animated pipeline walkthrough (Goal section)
  - `humanoid_real2sim_web.mp4` — Real2Sim overview demo (web-compressed from `humanoid_real2sim.mp4`)
  - `capture_scene.mp4` — captured 3DGS scenes across environments
  - `manipulation.mp4` — generated assets & egocentric manipulation trajectories
  - `loco_grasp_bedroom.mp4` — loco-grasp in a captured bedroom scene
- `static/` — Bulma CSS/JS (Nerfies template assets)
- `rss_workshop_humanoid_everywhere.pdf` — the paper
